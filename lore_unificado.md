## Crónica del lore — las seis eras

- **Era 0 — El caos.** Decenas de repos dispersos, versiones que se traicionan, herramientas sin mapa. El universo empieza como ruido.
- **Era I — Belentani (Nodo 01).** El núcleo absorbe el caos: monorepo, biblia y cierre de deuda técnica. El ruido se vuelve fundación.
- **Era II — El Artista (Nodo 02).** La mano humana: el código se convierte en obra — retratos, laberintos y el workflow creativo.
- **Era III — Neon Glassmorphism (Nodo 03).** Se fija la gramática estética: vidrio, neón y vacío como idioma común.
- **Era IV — The Judas Experience (Nodo 04).** El sistema comete un error con nombre: Judas. Traición, frecuencia, hackeo y redención.
- **Era V — Omega (Nodo 05).** El último nodo mira el lore a los ojos y decide continuar. Ninguna página es terminal.

## Las cuatro gemas de Judas

No se pueden saltar. Cada gema es una versión de la caída y el ascenso, y coincide con los
capítulos del artefacto antiguo:

1. **Traición — The Betrayal.** El algoritmo del dolor. El boot sequence se corta; la lluvia de código se tiñe de rojo. Lo que se creía estable revela su fragilidad.
2. **Frecuencia — The Trial.** Síntesis oscura a 432 Hz. El dolor, muestreado y procesado, se convierte en señal. El ruido no se elimina: se afina hasta que canta.
3. **Hackeo — The Revelation.** Sanación conceptual: se entra al propio sistema con permiso de uno mismo. Se parchea la herida en producción.
4. **Redención — The Redemption.** Elevación de código. Lo traicionado regresa reconstruido. La redención no borra la traición: la compila con optimizaciones.
