CORE SKILL

Meta-skill que orquestra todas as outras. Antes de qualquer ação — até de perguntar — verifica se existe uma skill aplicável e invoca-a. Estabelece a prioridade: skills de processo primeiro (brainstorming, debugging), depois skills de implementação (frontend, backend).

// Regra principal:
if (skillExists(task)) invoke(skill)
// Ordem: brainstorming → debugging → domain skills
process_skills.before(implementation_skills)

Ferramentas Frontend

FRONTEND TOOL

Image2CSS

Ferramenta que converte qualquer imagem em CSS puro usando a técnica de box-shadow. Um único <div> reproduz a imagem pixel a pixel — sem ficheiro de imagem, sem <img>, sem background-image. Ideal para logos, ícones e pixel art leves.

/* Um div, milhares de box-shadows */
.css-art {
  width: 1px; height: 1px;
  box-shadow:
    0px 0px #ff003c,
    1px 0px #ff285f,
    2px 0px #ffd45c,
    /* ... cada pixel = um shadow */
}

Ferramentas: image2css.com javier.xyz/img2css github.com/rivetin/Image2CSS
