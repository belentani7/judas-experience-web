## 🌌 CONCEPTO

**Judas no fue un villano. Fue el más cercano.**

En el vacío interestelar, donde la luz se curva y el tiempo se pliega, existe una historia que resuena a través de las galaxias. La historia del que amó demasiado. Del que traicionó por amor.

Esta experiencia web explora:
- 💰 **Las 30 monedas** - El precio de un dios
- 🌙 **La última noche** - Getsemaní y el cáliz
- ✞ **El beso** - La traición como acto supremo
- 🔥 **La redención** - ¿Puede la traición ser amor?
